发票自动扫描 - GitHub Actions 部署指南

用 GitHub 自带的定时任务自动扫描邮箱发票，零成本、免注册

🤔 两种方案对比

推荐 GitHub Actions

  • 完全免费（每月 2000 分钟额度）
  • 不用注册新账号
  • 配置简单，几步搞定
  • 代码和任务在一起，好维护
  • 每 30 分钟扫描一次

备选 腾讯云 SCF

  • 免费额度较少（每月 40 万次调用）
  • 需要注册腾讯云并实名认证
  • 配置稍复杂
  • 运行更稳定，国内速度快
  • 可设置更频繁的触发
建议：先用 GitHub Actions 方案，简单快捷。如果以后需要更高频率或更稳定，再迁移到腾讯云。

🔧 步骤一：开启企业微信邮箱 IMAP

1
登录企业微信邮箱
访问 https://exmail.qq.com/login
2
开启 IMAP 服务
「设置」→「客户端设置」→ 勾选 IMAP/SMTP服务
3
生成客户端专用密码
在「安全登录」或「客户端密码」处生成，保存好这个密码
必须使用客户端专用密码，不是网页登录密码！

🔐 步骤二：在 GitHub 仓库添加 Secrets

1
进入仓库 Settings
打开你的仓库：https://github.com/meidi0421/workbench
点击顶部的 Settings → 左侧找到 Secrets and variables → Actions
2
点击「New repository secret」添加以下 4 个 Secret
Secret 名称值说明
IMAP_USER你的企业邮箱地址如：yourname@company.com
IMAP_PASS客户端专用密码步骤一生成的密码
GIST_TOKENghp_xxxxxxxx你已有的 GitHub Token
GIST_IDxxxxxxxx你已有的 Gist ID
注意：Token 名称是 GIST_TOKEN，不是 GITHUB_TOKEN（后者是 GitHub 内置保留名）

🚀 步骤三：推送代码并启用 Actions

1
代码已准备好
.github/workflows/invoice-scanner.yml 已经创建，会随前端代码一起推送到 GitHub。
推送成功后，Actions 会自动启用。
2
手动触发第一次运行
进入仓库的 Actions 标签页 → 左侧选择 Invoice Scanner
→ 点击右侧 Run workflow → 选择 main 分支 → 点击 Run
稍等 1-2 分钟，查看运行结果。
3
查看运行日志
点击运行记录 → 展开 Run invoice scanner 步骤
可以看到扫描了多少封邮件、找到多少张发票、同步是否成功。

⏰ 定时说明

当前配置为每 30 分钟自动扫描一次邮箱。
扫描到的新发票会自动写入 Gist，你在工作台点击「拉取云端发票」即可同步到本地。

GitHub Actions 的定时任务可能有几分钟延迟，属于正常现象。

🧪 验证方法

✓
Actions 运行成功
在 GitHub Actions 页面看到绿色 ✓ 标记
✓
Gist 中有数据
访问你的 Gist 页面，确认 invoice_pool.json 文件存在并有内容
✓
工作台能拉取发票
打开工作台 → 发票页 → 点击「拉取云端发票」，能看到发票列表

⚠️ 常见问题

Actions 运行失败，提示邮箱连接错误

检查 IMAP_USER 和 IMAP_PASS 是否正确，确认使用的是客户端专用密码。

扫描到 0 张发票

可能最近几天没有发票邮件，可以调大 SCAN_DAYS 扫描更多天，或手动给邮箱发一封带「发票」关键词的测试邮件。

想修改扫描频率

修改 .github/workflows/invoice-scanner.yml 中的 cron 表达式即可。
