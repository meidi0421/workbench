项目说明状态

🔧 步骤一：开启企业微信邮箱 IMAP

1
登录企业微信邮箱后台
访问 https://exmail.qq.com/login，用管理员或成员账号登录。
2
开启 IMAP/SMTP 服务
进入「设置」→「客户端设置」，勾选 IMAP/SMTP服务。
记录服务器地址：imap.exmail.qq.com，端口：993（SSL）
3
生成客户端专用密码
在「客户端设置」中找到「生成专用密码」或「安全登录」。
生成的密码仅显示一次，请务必保存。这个密码将用于云函数登录邮箱。
注意：不要使用网页登录密码，必须使用客户端专用密码才能通过 IMAP 登录。

☁️ 步骤二：创建腾讯云云函数（SCF）

1
进入腾讯云云函数控制台
访问 https://console.cloud.tencent.com/scf，选择「函数服务」→「新建」。
2
选择「从头开始」创建
函数名称：填写 invoice-scanner
运行环境：选择 Python 3.9 或 Python 3.10
地域：选择离你最近的（如广州/上海）
3
上传代码
将 invoice_scanner.py 和 requirements.txt 打包成 zip 上传。
打包命令（Mac 终端执行）： 
zip invoice_scanner.zip invoice_scanner.py requirements.txt
然后在腾讯云控制台选择「本地上传 zip 包」，上传生成的 zip 文件。
4
配置入口函数
执行方法填写：index.main_handler（或根据实际入口调整，本脚本入口为 main_handler）

🔐 步骤三：配置环境变量

在函数配置页找到「环境变量」或「高级配置」，添加以下变量：

变量名值说明
IMAP_USER你的企业邮箱地址如：yourname@company.com
IMAP_PASS客户端专用密码步骤一生成的密码
GITHUB_TOKENghp_xxxxxxxx已有的 GitHub Token
GIST_IDxxxxxxxx已有的 Gist ID
SCAN_DAYS7每次扫描最近几天的邮件
IMAP_SERVER 默认为 imap.exmail.qq.com，如果使用其他邮箱可单独配置。

⏰ 步骤四：配置定时触发器

1
添加触发方式
在函数页面选择「触发管理」→「新建触发器」→「定时触发」。
2
设置触发周期
推荐每 30 分钟扫描一次：
Cron 表达式填写：0 */30 * * * *
或每天早晚各一次：0 0 9,18 * * * *
3
启用触发器
保存后，云函数会按设定周期自动执行，扫描邮箱中的新发票。

🧪 步骤五：测试运行

1
手动触发测试
在腾讯云控制台点击「测试」，查看执行日志。如果配置正确，会输出扫描到的发票数量和同步状态。
2
在工作台拉取发票
打开工作台 → 进入「发票」页面 → 点击「🔄 拉取云端发票」。
如果云函数已成功写入 Gist，工作台会自动获取并显示待匹配的发票。

⚠️ 常见问题

邮箱连接失败

确认企业邮箱已开启 IMAP，并使用客户端专用密码而非网页登录密码。

发票信息提取不完整

部分 PDF 发票为图片格式，文本提取可能失败。云函数会保留邮件主题和附件信息，你仍可在工作台手动补全。

Gist 写入失败

检查 GitHub Token 是否有 gist 权限，以及 Gist ID 是否正确。

费用在哪里查看

发票数据写入 Gist 的 invoice_pool.json，工作台通过「拉取云端发票」按钮同步到本地。
